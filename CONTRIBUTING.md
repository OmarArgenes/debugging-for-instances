# Contributing to DFI

DFI is currently a foundational research and methodological project. Contributions should improve clarity, reproducibility, validation quality, or the practical documentation of evidence-driven diagnosis.

## Useful contributions
- Reproducible DFI case studies.
- Controlled comparison protocols.
- Corrections to terminology or references.
- Examples from additional technology stacks.
- Improvements to templates and schemas.
- Authorized defensive-security cases.
- Replication results, including negative or inconclusive outcomes.

## Required structure for case studies
1. Observable symptom.
2. Environment and scope.
3. Initial hypotheses.
4. Each diagnostic test.
5. Captured evidence.
6. Hypothesis updates.
7. Identified cause or unresolved state.
8. Correction, if any.
9. Verification evidence.
10. Limitations and alternative explanations.

Start from `templates/dfi-case-template.md`.

## Scientific discipline
Do not describe a benefit as proven unless the submitted evidence supports it. Prefer measurable statements over subjective ones.

## Security and privacy
Only submit authorized, defensive material. Remove secrets, tokens, credentials, private user data, and customer-identifying information.

## Pull requests
Keep pull requests focused and explain what changed, why it improves DFI, whether it changes the methodology or only documentation/examples, and what evidence or references support the change.
