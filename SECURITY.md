# Security Policy

DFI may be applied to defensive security investigation, but this repository is not a vulnerability exploitation toolkit.

## Appropriate scope
- Unexpected files or modifications.
- Integrity anomalies.
- Permissions and configuration.
- Suspicious persistence indicators.
- Application and server logs.
- Authorized request or network evidence.
- Remediation verification.

## Do not submit
- Live credentials, API keys, session tokens, or private keys.
- Private customer or user data.
- Exploit chains intended for unauthorized access.
- Malware, credential theft, destructive payloads, or persistence tooling.

## Evidence handling
Sanitize screenshots, logs, requests, database records, and configuration before publication. Preserve enough structure for reproducibility without exposing secrets or personal data.
