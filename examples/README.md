# DFI Examples

These examples demonstrate how to represent an evidence-driven investigation. They are not claims that DFI automatically discovers root causes.

- `sample-case.json` — machine-readable exploratory case.
- `adaptive-probe-demo.js` — dependency-free teaching example of adaptive hypothesis updates.

Run:

~~~bash
node examples/adaptive-probe-demo.js
~~~

Security examples in this repository are intentionally limited to authorized defensive investigation.
